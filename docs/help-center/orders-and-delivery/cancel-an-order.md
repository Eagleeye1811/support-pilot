# Cancelling an order

You can cancel an order **free of charge until it ships**, while its status is *Placed* or *Packed*. Go to
**My Orders → Cancel**, or ask us in chat with your order ID.

- **Prepaid orders:** the full amount is refunded to your original payment method automatically, the moment the
  order is cancelled. See *How long do refunds take?* for how long it takes.
- **Cash on Delivery orders:** nothing to refund. The order is simply cancelled.

Once an order has **shipped** it can no longer be cancelled. Refuse the delivery instead (it is refunded when it
returns to us), or request a return after delivery.
