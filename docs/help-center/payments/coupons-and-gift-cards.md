# Coupons and gift cards

- Enter a coupon code at checkout under **Apply coupon**. Only one coupon can be used per order.
- Apology coupons we send after a service problem are valid for **60 days** and apply to your next order.
- Gift cards are added to your NovaPay wallet balance and can be used for any product. They can't be exchanged for
  cash.
- If an order paid partly with a coupon is returned, the coupon value isn't refunded. The coupon is restored if it
  is still within its validity.
