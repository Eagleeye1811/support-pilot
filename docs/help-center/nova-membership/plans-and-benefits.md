# Nova Plus and Nova Premium: plans and benefits

| | Nova Plus | Nova Premium |
|---|---|---|
| Price | ₹199 / month | ₹499 / month |
| Free delivery on every order | ✓ | ✓ |
| Replacement shipping | within 3 days | next day |
| Return window | standard | 30 days (except Beauty and Grocery) |
| Support response for urgent issues | within 1 hour | within 15 minutes |
| Delay apology coupon | ₹100 | ₹200 |

**Upgrading** takes effect immediately. You pay only the prorated difference for the rest of the current billing
cycle. Benefits appear once your membership syncs, usually within a few minutes.
