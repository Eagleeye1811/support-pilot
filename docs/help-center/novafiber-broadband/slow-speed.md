# Slow internet speed

- Test the speed with a laptop connected **by cable** to the router. Wi-Fi speeds are lower and vary from room to room.
- Use the **5 GHz** Wi-Fi network for streaming and video calls. It's faster but has a shorter range than 2.4 GHz.
- Keep the router in an open, central spot, away from microwaves and thick walls.
- Restart the router once a week.
- If wired speed is consistently below 70% of your plan, message us. We run line diagnostics and fix it remotely or
  send a technician.
