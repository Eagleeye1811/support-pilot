# Setting up or changing your Wi-Fi name and password

Open the **NovaFiber** section in the ShopNova app → **My router** → **Wi-Fi settings** to change the network name
and password. The router restarts and your devices reconnect with the new password.

You can also open http://192.168.1.1 from a device connected to the router. The default login is printed on the
sticker underneath it.
