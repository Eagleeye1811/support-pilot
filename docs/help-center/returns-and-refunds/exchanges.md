# Exchanging an item for a different size or colour

We don't do direct swaps yet. To get a different size or colour:

1. Place a new order for the size or colour you want. This holds the stock for you.
2. Return the original item within its return window. The pickup is free.
3. Your refund for the original item starts once it is picked up.

If we sent you the wrong size by mistake, you don't need to do this. See *I received the wrong item*.
